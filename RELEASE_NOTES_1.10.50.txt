🇭🇺 Magyar
- Javítva a verzióazonosítás: a főképernyő, a frissítésellenőrzés és a diagnosztikai napló automatikusan a Gradle verzióadatait használja.

🇬🇧 English
- Fixed version identification: the main screen, update checker and diagnostic log now use Gradle version metadata automatically.
- Fixed previous APK downloads on Android 6–9 by requesting the storage permission required for the public Downloads folder.
- Previous-version downloads remain manual; the current app must be uninstalled before installing an older version.
- The Zello installation reminder is unchanged.
- FTDI, RTS, CTS, PTT and audio-monitoring control logic remain unchanged.
