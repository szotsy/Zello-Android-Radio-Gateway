Orfeusz Gateway

An Android-based, bidirectional Zello-to-radio gateway. It connects conventional radio communications to the Zello network without a separate laptop or desktop computer.

Download the latest APK Open GitHub project Wiring guide

How does it work?

Radio → Zello

Audio received by the connected conventional radio can be forwarded to users in the Zello channel.

Zello → Radio

Incoming audio from Zello can be relayed through the gateway and connected radio to nearby radios.

Mobile deployment

The Android phone runs the gateway application. No separate PC is required; power and internet access are still necessary.

Android version compatibility

Minimum supported Android version: Android 6.0 (Marshmallow, API 23).

The source project allows installation on Android 6.0 and newer versions. Android 11+ package visibility requirements are handled by the project and do not restrict older Android versions.

This minimum version reflects the project configuration; it does not mean every Android version and device has been individually tested.

Required hardware

  • Modified Baofeng UV-5R or BF-888S radio.
  • Dedicated radio interface.
  • Verified USB–UART adapter: FTDI FT232R (VID: 0403, PID: 6001).

A stock Baofeng radio and a simple USB cable are not sufficient. See the wiring guide for the radio interface diagram and detailed hardware documentation.
