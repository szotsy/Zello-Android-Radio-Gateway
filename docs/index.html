Orfeusz Gateway – központi kapuhálózat

Az Orfeusz Gateway Zello-csatorna a rendszer központi gyűjtőpontja: a különböző helyszíneken működő Orfeusz Gateway kapuk ezen a közös csatornán keresztül kapcsolódhatnak egymáshoz. Így a csatlakoztatott kapuk rádiós forgalma a hálózat többi résztvevője számára is elérhetővé válhat.

Bármely Orfeusz Gateway üzemeltető kérheti a csatlakozást. A kapu csatlakoztatása és beszédjogának engedélyezése moderátori jóváhagyáshoz kötött. A csatorna nyilvánosan hallgatható a Zello felületén.

Hogyan működik?

Rádió → Zello

A csatlakoztatott hagyományos rádión vett hang továbbítható a Zello-csoport felhasználói felé.

Zello → rádió

A Zello felől érkező hang a kapuállomáson keresztül, a csatlakoztatott rádió segítségével továbbítható a közeli rádiókra.

Mobil kialakítás

Az Androidos telefon futtatja a gateway alkalmazást. Nincs szükség külön PC-re; tápellátás és internetkapcsolat továbbra is szükséges.

Android-verzió kompatibilitás

Minimálisan támogatott Android-verzió: Android 6.0 (Marshmallow, API 23).

A forrásprojekt beállítása alapján az alkalmazás Android 6.0-tól újabb Android-verziókon is telepíthető. Az Android 11-től érvényes csomagláthatósági szabályokat a projekt kezeli; ezek a régebbi rendszerek működését nem korlátozzák.

A minimális verzió a projekt konfigurációját jelöli, nem jelenti azt, hogy minden Android-verzió és készülék külön tesztelve lett.

Szükséges hardver

  • Átalakított Baofeng UV-5R vagy BF-888S rádió.
  • Külön rádióinterfész.
  • USB–UART adapter.

USB–UART kompatibilitás: az alkalmazás többféle USB–UART adaptert kezel. Vásárlás előtt mindig ellenőrizd a központi kompatibilitási nyilvántartást; az adapterek neve, azonosítója és tesztállapota ott naprakészen szerepel.

Egy gyári Baofeng rádió és egy egyszerű USB-kábel önmagában nem elegendő. A részletes hardveres bekötési dokumentáció a bekötési útmutatóban található.
