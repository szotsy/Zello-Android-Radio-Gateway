Android-alapú, kétirányú Zello–rádió kapuállomás. Összekapcsolja a hagyományos rádióforgalmat a Zello-hálózattal – külön laptop vagy asztali számítógép nélkül.

Hogyan működik?

Rádió → Zello

A csatlakoztatott hagyományos rádión vett hang továbbítható a Zello-csoport felhasználói felé.

Zello → rádió

A Zello felől érkező hang a kapuállomáson keresztül továbbítható a csatlakoztatott rádióra.

Mobil kialakítás

Az Androidos telefon futtatja a gateway alkalmazást. Nincs szükség külön PC-re; tápellátás és internetkapcsolat továbbra is szükséges.

Szükséges hardver

  • Átalakított Baofeng UV-5R vagy BF-888S rádió.
  • Külön rádióinterfész.
  • Igazolt USB–UART adapter: FTDI FT232R (VID: 0403, PID: 6001).

Egy gyári Baofeng rádió és egy egyszerű USB-kábel önmagában nem elegendő. A hardveres kapcsolási rajzok és a részletes építési dokumentáció külön készülnek.

A rendszer bemutatása

Az alábbiak szemléltető, AI-val újrarenderelt képek az eredeti rendszerről készült fényképek alapján. Az elektromos kapcsolás és az apró részletek nem feltétlenül pontosak; építéshez kizárólag az ellenőrzött műszaki dokumentáció használható.

Orfeusz Gateway

An Android-based, bidirectional Zello-to-radio gateway. It connects conventional radio communications to the Zello network without a separate laptop or desktop computer.

Download the latest APK Open GitHub project

How does it work?

Radio → Zello

Audio received by the connected conventional radio can be forwarded to users in the Zello channel.

Zello → Radio

Incoming audio from Zello can be transmitted through the gateway to the connected radio.

Mobile deployment

The Android phone runs the gateway application. No separate PC is required; power and internet access are still necessary.

Required hardware

  • Modified Baofeng UV-5R or BF-888S radio.
  • Dedicated radio interface.
  • Verified USB–UART adapter: FTDI FT232R (VID: 0403, PID: 6001).

A stock Baofeng radio and a simple USB cable are not sufficient. Verified circuit diagrams and detailed build documentation are being prepared separately.
