Getting Started in 5 Steps

This page walks you through the basic steps required for your first use of Orfeusz Gateway. If you already have the required hardware, continue to the connection step.

⬇ Download APK
01

Check that you have the required hardware

The application is not a radio by itself. The following setup is required:

  • Modified Baofeng UV-5R or BF-888S radio.
  • Dedicated radio interface.
  • Verified FTDI FT232R USB–UART adapter (VID: 0403, PID: 6001).

Other USB–UART adapters, including CH340G, are not verified. Before purchasing, check that both CTS and RTS signals are exposed on the FTDI adapter.

02

Download and install the application

Download the latest stable official APK from GitHub Releases. On Android, you may need to allow the browser or file manager to install apps from that source.

If an earlier version of Orfeusz Gateway is already installed, the newer official APK can normally be installed as an update. If Android reports a signature or package conflict, do not automatically uninstall the existing application.

03

Prepare the Zello application

Install Zello on the same Android device and complete the account and channel configuration required for your intended use.

Important: before using Orfeusz Gateway, enable Do Not Disturb on this device. Otherwise, phone notification sounds may be transmitted over the radio.

Zello account and channel setup are not part of the Orfeusz Gateway installer; configure them separately in the Zello application.

Detailed illustrated Zello settings guide

04

Connect the radio interface

Connect the radio, dedicated radio interface and FTDI FT232R adapter according to the documented wiring, then connect the adapter to the Android device.

When Android asks for USB access, verify the device and grant permission. The wiring guide contains the connector pin assignments and parts list.

Open wiring diagram and parts list

05

Check the status before first use

Launch Orfeusz Gateway and check the FTDI, radio and Zello connection indicators in the app. Grant the required permissions requested by Android.

If any connection is not active, do not start radio operation. First check the connections, USB permission, Zello operation and power supply.

Important: Do not rely on illustrative photos or generic USB cables for hardware wiring. Use the project's verified circuit diagram and the actual signal labels on your specific FTDI adapter.
