USB–UART compatibility

Track USB–UART adapters evaluated for the Orfeusz Gateway radio interface and request testing for another adapter.

Important: “Not verified” does not mean incompatible. An adapter is listed as supported only after testing confirms its operation. In addition to the FTDI FT232R, RTS/CTS and PTT operation has been successfully tested with one WCH CH340G adapter. This result applies to the tested adapter; breakout-board implementations may differ.

Request an adapter compatibility test

If you own a USB–UART adapter you would like to use with Orfeusz Gateway, submit a request. The form asks for the chip, VID/PID, Android device and the RTS/CTS/PTT tests you can perform.

Requests are recorded as GitHub Issues so the investigation status and results can be tracked. A GitHub account is required.

Submit compatibility request ↗

How compatibility is evaluated

  1. Identify the adapter and Android device (chip, VID/PID, Android version).
  2. Check USB detection and Android access permission.
  3. Test RTS/CTS, followed by PTT and radio RX/TX where a suitable test setup is available.
  4. Document the result. An adapter is moved to the verified list only after successful, repeatable testing.

Test radio transmission only in a suitable, safe and lawful environment. Do not transmit without authorization or open powered equipment.
