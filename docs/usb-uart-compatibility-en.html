Request evaluation of a new adapter

Do you own a USB–UART adapter that is not listed among the supported models? Use this request to ask for an initial evaluation and, if technically suitable, possible integration into the Orfeusz Gateway common USB-UART engine.

The form lets you provide the manufacturer, exact model, VID/PID, whether you own the adapter and whether you can help with testing. You can also attach photos and a product link.

Important: a request does not guarantee engine integration or compatibility approval. The project maintainer will review the adapter and its required serial control signals.

Request USB–UART adapter evaluation

Test submission requirements

Test reports can be submitted only for adapter models whose driver is explicitly integrated and enabled in the current Orfeusz Gateway USB engine. Support in the underlying serial library alone is not sufficient.

New adapter families become selectable only after their drivers are implemented and enabled in the app engine.
