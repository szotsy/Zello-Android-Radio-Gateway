# Telepítés / Installation

> **Képfrissítés később / Images to be added later:** a telepítési lépésekhez képernyőképek kerülnek majd.

## Magyar

1. Töltsd le a [legfrissebb stabil APK-t](https://github.com/szotsy/Zello-Android-Radio-Gateway/releases/latest/download/Orfeusz.Gateway.apk).
2. Nyisd meg a letöltött APK-fájlt Androidon.
3. Ha a rendszer kéri, engedélyezd az adott forrásból származó alkalmazás telepítését.
4. Fejezd be a telepítést, majd indítsd el az Orfeusz Gateway alkalmazást.
5. Csatlakoztatás és konfigurálás előtt olvasd el a [hardver- és bekötési útmutatót](Hardware-and-wiring.md).

**Fontos:** csak megbízható forrásból származó APK-t telepíts. A hivatalos kiadásokat a projekt GitHub Releases oldalán találod.

### Később hozzáadandó képek
- APK letöltése a weboldalról.
- Android telepítési figyelmeztetés és engedélyezés.
- Sikeres telepítés és első indítás.

## English

1. Download the [latest stable APK](https://github.com/szotsy/Zello-Android-Radio-Gateway/releases/latest/download/Orfeusz.Gateway.apk).
2. Open the downloaded APK file on Android.
3. If prompted, allow installation from that source.
4. Complete installation and launch Orfeusz Gateway.
5. Read the [hardware and wiring guide](Hardware-and-wiring.md) before connecting and configuring the equipment.

**Important:** install APK files only from trusted sources. Official releases are available on the project GitHub Releases page.
